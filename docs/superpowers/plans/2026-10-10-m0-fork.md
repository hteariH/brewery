# Brewery M0 — Fork Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a fork of Zed into "Brewery": it builds on Windows and Linux, presents itself as Brewery, never talks to Zed's cloud, and has its own green CI.

**Architecture:** The fork is Zed's `main` plus a small set of Brewery commits. Brewery code lives in new `brewery_*` crates; edits inside Zed's own files are short hook-ins marked `brewery:` so upstream merges stay small. Cloud features are not deleted (that would conflict on every merge) — they are switched off by default settings, hidden from the command palette, and hard-gated in code by one constant.

**Tech Stack:** Rust (toolchain pinned by Zed's `rust-toolchain.toml`), GPUI, Cargo, GitHub Actions, Python 3 + Pillow (icon generation only).

**Spec:** `docs/superpowers/specs/2026-10-10-brewery-design.md`

## Global Constraints

- Fork licence: GPL-3 (Zed's licence files stay untouched).
- No JetBrains names, logos or product icons anywhere.
- Every edit inside a file that came from Zed carries a `brewery:` marker comment (`// brewery:` in Rust and JSONC, `# brewery:` in TOML/YAML/shell). New Brewery-only files do not need markers.
- Do not rename or delete Zed crates; do not rename the `zed` package or its `[[bin]]` (binary rename belongs to M6 packaging).
- Removed from Zed per spec: collaboration, Zed account and cloud, Zed AI, telemetry to Zed servers. Zed's extension gallery stays available.
- Supported platforms: Windows and Linux. macOS: unsigned, unsupported build only.
- Platform app id: `io.github.htearih.Brewery` (channel suffixes `-Dev`, `-Nightly`, `-Preview`).
- Windows instance identifier prefix: `Brewery-Editor-` (must never equal Zed's `Zed-Editor-`, or Brewery would hand its arguments to a running Zed).
- Git: `core.autocrlf=false` in this repository (Zed's shell scripts must keep LF).
- Public text (README, docs, commit messages, UI) is in English.

## Scope notes

- Visible "Zed" strings beyond the central names (welcome page, onboarding, menus) are M1 work.
- Auto-update is switched off entirely; M6 points it at GitHub Releases.
- Packaging (installers, `.deb`, `.rpm`, AUR) is M6.

`script/brewery/gen_app_icon.py`:

```python
"""Generate Brewery's placeholder app icons over Zed's icon files.

Each existing icon is replaced by one of the same size. Channel variants get a
coloured corner badge. Run from the repository root:
    python script/brewery/gen_app_icon.py
"""

from pathlib import Path

from PIL import Image, ImageDraw, ImageFont

RESOURCES = Path("crates/zed/resources")
BADGES = {"dev": (90, 160, 90), "nightly": (90, 110, 200), "preview": (200, 150, 60)}
ICO_SIZES = [(16, 16), (24, 24), (32, 32), (48, 48), (64, 64), (128, 128), (256, 256)]


def channel_of(path: Path) -> str | None:
    stem = path.stem.replace("@2x", "")
    suffix = stem.removeprefix("app-icon").removeprefix("-")
    return suffix or None


def draw_icon(size: int, channel: str | None) -> Image.Image:
    image = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    draw = ImageDraw.Draw(image)
    margin = size // 16
    box = (margin, margin, size - margin, size - margin)
    draw.rounded_rectangle(box, radius=size // 5, fill=(122, 74, 34))
    inner = (margin * 2, margin * 2, size - margin * 2, size - margin * 2)
    draw.rounded_rectangle(inner, radius=size // 6, fill=(199, 125, 58))
    font = ImageFont.load_default(size=int(size * 0.62))
    draw.text((size / 2, size / 2), "B", font=font, fill=(255, 248, 235), anchor="mm")
    if channel:
        r = size // 5
        draw.ellipse((size - margin - 2 * r, size - margin - 2 * r, size - margin, size - margin),
                     fill=BADGES[channel], outline=(255, 255, 255), width=max(1, size // 64))
    return image


def main() -> None:
    pngs = sorted(RESOURCES.glob("app-icon*.png"))
    icos = sorted((RESOURCES / "windows").glob("app-icon*.ico"))
    if not pngs or not icos:
        raise SystemExit("run from the repository root; Zed icon files not found")
    for path in pngs:
        width, _ = Image.open(path).size
        draw_icon(width, channel_of(path)).save(path)
        print(f"{path} {width}x{width}")
    for path in icos:
        draw_icon(256, channel_of(path)).save(path, sizes=ICO_SIZES)
        print(f"{path} ico")


if __name__ == "__main__":
    main()
```

```rust
use gpui::App;

/// Brewery never talks to Zed's cloud: no Zed account sign-in, collaboration,
/// Zed AI, telemetry upload or Zed update checks. Hook-ins in Zed's crates
/// check this instead of each carrying its own switch.
pub const ZED_CLOUD_ENABLED: bool = false;

/// Command palette namespaces whose actions only work with a Zed account.
pub const HIDDEN_CLOUD_NAMESPACES: &[&str] = &["client", "collab", "collab_panel", "auto_update"];

/// Hides Zed-cloud actions. Call after `command_palette::init`.
pub fn init(cx: &mut App) {
    CommandPaletteFilter::update_global(cx, |filter, _| {
        for namespace in HIDDEN_CLOUD_NAMESPACES {
            filter.hide_namespace(namespace);
        }
    });
}
```

- [ ] **Step 4: Write `script/brewery/merge-upstream`**

```bash
#!/usr/bin/env bash
# Merges Zed's main into the current branch and resolves the conflicts that
# always resolve the same way. Exits 1 and lists what is left for a human.
set -euo pipefail
cd "$(git rev-parse --show-toplevel)"

git fetch --filter=blob:none upstream main
git merge --no-edit --no-commit upstream/main || true

if ! git rev-parse -q --verify MERGE_HEAD >/dev/null; then
  echo "Already up to date with upstream/main."
  exit 0
fi

for path in $(git diff --name-only --diff-filter=U); do
  case "$path" in
    .github/workflows/brewery_*) ;;
    .github/workflows/*) git rm -q --ignore-unmatch -- "$path" ;;
    README.md) git checkout --ours -- README.md && git add README.md ;;
  esac
done

# Upstream may add new workflows without conflicting; drop them too.
git ls-files .github/workflows | grep -v '/brewery_' | xargs -r git rm -q --

remaining=$(git diff --name-only --diff-filter=U)
if [ -n "$remaining" ]; then
  echo "Resolve these by hand, then run 'git commit':"
  echo "$remaining"
  exit 1
fi

git commit --no-edit
echo "Merged upstream/main."
```

```yaml
      fail-fast: false
      matrix:
        include:
          - os: ubuntu-24.04
            binary: target/release-fast/zed
          - os: windows-2025
            binary: target/release-fast/zed.exe
          - os: macos-15
            binary: target/release-fast/zed
            unsupported: true
    continue-on-error: ${{ matrix.unsupported == true }}
    runs-on: ${{ matrix.os }}
    timeout-minutes: 240
    steps:
      - name: Free disk space
        if: runner.os == 'Linux'
        uses: jlumbroso/free-disk-space@v1.3.1

          tool-cache: false
      - uses: actions/checkout@v4

      - uses: Swatinem/rust-cache@v2

          shared-key: brewery-build
```
